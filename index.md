# Privacy Policy — JAPAN Cardz AI

**Last updated: October 12, 2026**

## 1. About This Application

JAPAN Cardz AI is a tool used to assist with identifying collectible cards, researching listing prices, and preparing product listings for the JAPAN Cardz eBay store.

## 2. Information We Process

The application may process product photographs, card identification details, product descriptions, pricing information, and information needed to access the connected eBay seller account.

## 3. How Information Is Used

Information is used to identify products, research market prices, generate listing descriptions, and prepare eBay listings.

## 4. Third-Party Services

The application uses the OpenAI API for image analysis and text generation and the eBay API for marketplace-related functions.

Information sent to these services is handled according to their applicable policies.

## 5. Data Storage and Security

Application files and generated listing data may be stored locally by the application operator. API credentials are intended to be kept private and are not published on the public website.

## 6. Data Sharing

We do not sell personal information. Information may be transmitted to service providers as necessary to operate the application.

## 7. Data Retention and Deletion

Locally stored application data is retained as needed for operation and may be deleted by the application operator. Requests concerning personal data can be sent to the contact address below.

## 8. Changes to This Policy

This policy may be updated when application functionality or data handling practices change.
